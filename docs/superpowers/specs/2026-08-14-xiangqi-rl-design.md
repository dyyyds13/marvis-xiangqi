## 1. 总体目标

开发中国象棋桌面应用，内置两条 AI 路径：

- **经典基线 AI**（alpha-beta 搜索）：第一天即可玩，覆盖"新手~业余"强度。
- **强化学习 AI**（AlphaZero 式自我对弈）：后台持续训练，目标棋力突破业余中上水平，最终击败用户（用户自评业余中上）。

## 2. 环境约束

- Windows 11，纯 CPU（无 NVIDIA GPU），Python 3.11.8。
- 训练时间无上限（用户接受连续跑几天）。
- 必须充分利用多核 CPU（多进程并行自我对弈）。

## 3. 技术栈

| 组件 | 选型 | 理由 |
|---|---|---|
| 语言 | Python 3.11 | 已就绪 |
| GUI | PySide6 | 桌面原生、样式可控 |
| 规则引擎 | python-chess（中国象棋变体） | 走法/将军/胜负判定零 bug |
| 神经网络 | PyTorch（CPU） | 生态成熟 |
| 训练加速 | multiprocessing 并行自我对弈 | 榨干多核 CPU |

## 5. 功能清单

- 人机对战（用户执红先行，AI 执黑；可交换先后手）。
- 悔棋 / 重开一局。
- 走法提示（AI 推荐一步）。
- 难度分级（经典 AI 深度档 + RL 强度档）。
- 棋谱保存（PGN）与复盘回放。
- 训练状态面板：训练盘数、当前胜率、模型进度；边玩边训。
- GUI 要求：精致棋盘（木质/深色主题）、走法高亮、将军提示、棋子动画。

## 6. 神经网络设计（CPU 友好）

- 输入：棋盘编码为多通道张量（棋子位置按红黑、兵种分组 + 轮到方 + 将军状态等），9x10。
- 主干：2~3 层小型卷积 + 残差连接，通道数 32~64。
- 输出：策略头（全部合法走法概率分布）+ 价值头（胜率标量）。
- 参数量目标：~1M，单次前向推理 <30ms（CPU）。

## 7. MCTS 设计

- AlphaZero 式：UBC 公式（pUCT），先验来自策略网络。
- 叶节点评估 = 价值网络输出（无 rollout）。
- 虚拟损失支持并行搜索；transposition table 复用局面。
- 自我对弈温度调度：开局高温度鼓励探索，中局逐渐降低，残局接近贪心。

## 8. 训练机制

1. 多进程并行自我对弈（每进程独立 MCTS 树，进程数 = CPU 核心数 - 1）。
2. 对局样本（局面、策略、结果 z）写入共享回放池（文件/内存队列）。
3. 训练循环从回放池采样，优化：策略交叉熵 + 价值 MSE + L2 正则。
4. 定期评估：新模型挑战基线 AI / 旧模型，胜率 ≥55% 才替换；始终保留最强模型。
5. 训练进程独立于 GUI（不卡界面）；模型热更新（GUI 周期性加载最新权重）。
6. 容错：模型文件缺失/损坏、训练未开始时，AI 自动回退经典 alpha-beta。

## 9. 经典基线 AI

- alpha-beta 剪枝 + 迭代加深 + 手工评估函数。
- 评估函数：子力价值（车马炮兵仕相帅）、位置活性、将帅安全、进攻性惩罚/奖励。
- 深度分档对应难度分级（如 1/2/4 层）。

## 10. 数据流

```
GUI 人机对局 ──> AI 决策（经典 or RL 模型+MCTS）
RL 训练进程：自我对弈 ──> 样本池 ──> 网络训练 ──> 模型文件 ──> GUI 热加载
训练评估：新模型 vs 基线/旧模型 ──> 胜率达标 ──> 替换当前最佳模型
```

## 11. 错误处理与容错

- 首次运行自动检查并安装依赖（pip）。
- 训练进程崩溃：GUI 提示并自动重启训练进程。
- 模型文件缺失/损坏：回退经典 AI 并提示。
- PGN 写入失败：提示用户磁盘空间/权限问题。

## 12. 测试策略

- 规则引擎单测：走法合法性、将军/绝杀、胜负判定（使用 python-chess 内置测试 + 自编用例）。
- AI 对弈测试：经典 AI 自战 20 盘统计胜率分布；RL 评估赛自动跑。
- GUI 冒烟测试：启动、走子、悔棋、重开、提示、复盘流程手工验证。

## 13. 里程碑

- **M1**：核心规则 + 经典 AI + 精致 GUI，当天可玩。
- **M2**：网络 + MCTS + 单进程自我对弈闭环。
- **M3**：多进程训练加速 + 模型热更新 + 训练面板。
- **M4**：棋谱复盘/提示等全部功能 + 启动长时训练。
